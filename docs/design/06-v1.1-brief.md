## Arbitrages VALIDÉS (ne pas changer)

- Fond nuit pétrole ; jaune = moi / CTA / sélection ; corail = rival / accent secondaire ; or = rang / récompense / prestige.
- Vert = succès ; rouge = erreur ; crème = texte et plaques d'icônes ; violet = Premium / Flawless uniquement.
- Lucide pour l'interface, SVG SKILKI V2 sur plaque crème pour les thèmes.
- Jamais de retour au violet / cyan néon.

## Objectif V1.1

Garder ~90 % de la cohérence actuelle et ajouter ~10 % de spectacle **uniquement aux moments émotionnels** : VS, bonne réponse, victoire, montée de niveau, récompense rare. La navigation reste calme. Le spectacle vient de l'**animation et de la composition**, pas d'un excès de couleurs : pas de festival de halos, pas de particules permanentes, pas d'effets lourds.

## Règles strictes pour chaque agent

1. Ne modifier QUE les fichiers de ta mission. Interdit : `theme/*`, `utils/i18n.ts`, `app/_layout.tsx`, les autres écrans, et `components/ui/*` sauf mention explicite dans ta mission.
2. **Aucune logique métier modifiée** : API, WebSocket, navigation, minuteries, forfaits, scores, correctifs du Lot 0. Présentation et mise en page seulement.
3. **Zéro nouvelle dette** : pas de hex, rgba, fontSize, fontWeight ni LinearGradient hors `GRADIENTS`. Utiliser `COLOR` / `alpha(PALETTE.x, a)` / `TYPO` / `SPACE` / `RADII` / `<Txt>` / `<Icon>`. `node scripts/design-guard.js` ne doit montrer aucune régression.
4. **Nouveaux textes** : `t('pilot.<ecran>.<nom>')`, avec une clé déclarée dans ton rapport (fr, en, es, de, pt, it, ar, ja, ko, zh). Ne pas modifier `i18n.ts`.
5. **Animations** : Reanimated ou Animated, `useNativeDriver` quand c'est possible, durées courtes (< 600 ms pour les impulsions), rien en boucle infinie hors pulsation déjà existante. Respecter « réduire les animations » si c'est facile (`AccessibilityInfo.isReduceMotionEnabled`).
6. **Petits écrans** : la mise en page doit tenir en 390×844, 375×812, 360×800 et rester utilisable en 320×568 (pas de CTA hors écran, pas de chevauchement, pas de texte important coupé, cibles de 44 px). Prévoir des valeurs longues : pseudos de 20 caractères, noms de thèmes longs, stats à 4 ou 5 chiffres.
7. **Avant de rendre** :
   - `cd frontend && npx tsc --noEmit 2>&1 | grep <tes fichiers>` : aucune erreur nouvelle ;
   - `node scripts/design-guard.js` : aucune régression.

   Ne lancer ni serveur, ni navigateur, ni git.
8. **Rapport final**, en français, en texte :
